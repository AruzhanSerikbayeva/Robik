РОБИК ЖӘНЕ ҚУАТ — «Санның квадраты және кубы» қайталау сабағы
=============================================================

ІСКЕ ҚОСУ
1. ZIP-ті ашыңыз (Extract All).
2. index.html файлын екі рет басыңыз (Chrome / Edge ұсынылады). Интернет қажет емес.
3. «Бастау» батырмасын басыңыз — Робик шығады және сөйлейді (дыбысты қосыңыз!).
   Тақтаға шығару үшін F11 немесе «толық экран» батырмасы.

САБАҚ БАРЫСЫ (≈ 10–12 минут)
  Кіріспе            — Робик (қуаты 10%) өзін таныстырады, сабақ тақырыбын айтады
  1-ойын  Сызба есеп — 6-тапсырма: Айзере мұз айдынында, шаңғымен, жаяу жүреді; сызбаға қарап есеп шығарады
  2-ойын  Шытырман   — 7-тапсырма: 12 кедергі, 4 топ (әрқайсысына 3 тапсырма), топ кездейсоқ шақырылады
  3-ойын  Ақиқат/жалған — 8-тапсырма: 60 секундтық сынақ
  Қорытынды          — Робик 100% зарядталады, алғыс айтады, қолдарды көтертеді, стикер туралы айтады

БАСҚАРУ
  Тоқтату / Жалғастыру — жоғарғы оң жақтағы батырма (немесе Esc)
  Ойынды аяқтау        — барлық ойынды тоқтатады, Робик бірден 100% болады (уақыт жетпесе)
  1 · 2 · 3            — жоғарғы сол жақтағы батырмалар: кез келген ойынға өту
  Жылдамдату           — 1-ойында анимацияны жылдамдатады
  Жауап енгізу         — экрандағы пернетақта немесе компьютер пернетақтасы (сандар, Enter, Backspace)

РОБИКТІҢ ДАУСЫ
  Дауыс — audio/ папкасындағы mp3 файлдар (55 реплика, қазақша, робот дауысы). Интернет қажет емес.
  Өз дауысыңызбен ауыстыру: audio/i1.mp3, i2.mp3 ... файлдарын сол атпен жазып қойыңыз.
  Егер браузерде қазақша дауыс болса (мысалы, Microsoft Edge: Aigul/Daulet), «Тоқтату» терезесінде
  «Дауыс: Робот / Браузер» таңдауы шығады.

ИНТЕРНЕТКЕ ШЫҒАРУ (Vercel / Netlify / GitHub Pages)
  ZIP-тің ІШІНДЕГІ файлдарды (index.html, style.css, *.js, audio/) репозиторийдің түбіріне (root) салыңыз.
  index.html сайттың түбірінде тұруы керек — ішкі папкада емес.

-----------------------------------------------------------------
RU: распакуйте архив → откройте index.html → «Бастау». Работает офлайн.
Файлы лежат прямо в корне архива (без вложенной папки) — для Vercel/GitHub Pages загружайте их в корень репозитория.
Голос Робика — заранее сгенерированные mp3 (espeak-ng, казахский язык, эффект «робот»).
